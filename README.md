# Mobile Sales Dashboard (Power BI)

An interactive Power BI dashboard that analyzes mobile phone sales data and shows key sales KPIs, trends and customer insights on a single page.

## Dashboard Preview
[Dashboard](screenshots/dashboard.png)

## Objective
To turn raw mobile sales data into clear insights that help understand sales performance by product, brand, location, payment method and time.

## Tools Used
- Power BI (dashboard design, DAX measures)
- Microsoft Excel (source data)

## Key Metrics (KPIs)
- Total Sales
- Total Quantity
- Transactions
- Average Sales

## Dashboard Features
- Sales by mobile model (column chart)
- Sales by payment method (pie chart)
- Sales by day of the week (area chart)
- Sales trend over time (line chart)
- Sales by city (map)
- Brand-wise quantity, sales and transactions (table)
- Customer ratings (funnel chart)
- Slicers to filter by mobile model and date

1. Download `Sales_Data.pbix`.
2. Open it in Power BI Desktop.
3. Use the slicers to explore the data.
